FFHN83-19D0 vs FFHN83-25A4
CP1 / CP2 / CP3 測項筆數比對

測項筆數、Bin 分佈、量測值分佈是否有明顯差異？

資料日期：2026-11-10　｜　19D0 = OK　25A4 = NG

比對範圍與方法

  • 檔案：dlogTDO 共 6 份（19D0 與 25A4 各 CP1、CP2、CP3）
  • 逐一統計每個測項欄位「有量測值」的 die 筆數
  • 以 測項群組 + 測項名稱 對應兩片 wafer，檢查欄位是否缺漏
  • 因各 CP 的 die 數不同，另以「筆數 ÷ 該 CP die 數」換算涵蓋率再比較
  • Bin 分佈：統計每個 CP 各 Bin 的 die 數（Bin 1 = Pass，與檔頭 Pass 數一致）
  • 量測值：428 個測項欄位逐欄比較中位數位移（以 OK 片的 IQR/1.349 為單位）與超規筆數（依檔內 limit）

兩片是不同 wafer，沒有逐 die 對位；位移大小以 OK 片自身的離散度做參考。

  • OK 片同一測項有 1 顆超規（Serial 2330，BP44V 98 µA，也是 Bin 18）
  • 3 顆 die 位置分散（XY 38,21 / 34,30 / 47,41），佔 NG 片 CP2 的 0.12%，差異只有 3 顆 vs 1 顆

超規讀值是各欄位逐筆累計，同一顆 die 可能被計多次。

結論

  • 筆數、Bin、量測值三方面都沒有明顯差異：涵蓋率差最大 0.62 pp，中位數位移最大 1.12σ
  • 原始筆數差來自 NG 片 CP2、CP3 多 15~16 顆 die，與測項本身無關
  • NG 片的 Pass 比例（Bin 1）在三個 CP 都略高於 OK 片
  • 唯一可留意：CP2 Stand by current 有 3 顆 die 約 90~105 µA（OK 片 1 顆），數量太少，不足以說是異常
  • 單看這份 CP 資料，看不出 25A4 比 19D0 差

建議下一步：確認 25A4 被判 NG 的依據（例如 wafer map 空間分佈、Strip test 或其他站別），再針對該項比對。
