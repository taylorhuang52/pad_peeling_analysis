07 / 09
關鍵判讀

CP 測試攔不下 pad peeling，但訊號已經存在

  1. 兩片晶圓在四個項目上都 100% 在規格內，沒有任何 spec 離群 —— 也就是說，5.6% 的 pad peeling 不是 CP 測試能攔下來的失效，CP 判定兩片都是好的。
  2. 但統計分布已經明顯不同 —— 11 號片在 CP-3 的 D Pull 電阻與 DIF 都呈現整片一致的偏移， 代表訊號其實已經存在，只是被寬鬆的規格界限掩蓋住。
  3. D Pull 電阻偏高與 pad peeling 有合理的物理關聯 —— 下拉路徑電阻上升可能反映 pad 金屬層較薄、或 pad 與底層接觸狀態較差， 而這正是打線時容易發生 peeling 的條件。
08 / 09
建議行動

下一步

  1. 將 CP-3 的 Ohm@14V D Pull L Res 列為 pad peeling 的候選預警指標， 這是四項中判別力最強的項目（Cohen's d = −1.66）。
  2. 回頭比對更多批次（特別是先前分析的 FFHN83 系列高不良率批）， 驗證「D Pull 電阻越高 → peeling 率越高」這個關聯是否穩定成立。
  3. 若關聯成立，即使數值仍在規格內，也可用統計管制界限（例如平均值 +2σ） 提前篩出高風險晶圓，不必等到打線後才發現 peeling。
  4. 同步排查晶圓製程端：確認 06 與 11 兩片在金屬層厚度、接觸電阻、pad 表面處理上 是否存在已知的製程差異，以解釋整片一致偏移的成因。
